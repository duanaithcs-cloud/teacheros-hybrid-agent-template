# Start Here

## Daily Use

1. Double-click `0_Start_TeacherOS.bat`.
2. Wait until Claude Code opens in the terminal.
3. Give a task, for example:

```text
Create a Grade 9 Geography lesson plan following GDPT 2018 and Cong van 5512. Export DOCX and include digital competence tasks.
```

## First-Time Setup

Run:

```bat
scripts\setup.bat
```

Paste your Google AI Studio API key. The script creates ignored local config files.

## Do Not Use for Heavy Work

Avoid Cursor built-in `Auto`, `Cursor Grok`, `Cursor Claude`, and `Cursor GPT` if you want to avoid Cursor quota usage.
