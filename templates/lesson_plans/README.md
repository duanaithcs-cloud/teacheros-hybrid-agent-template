# Lesson Plan Template

Use this folder for generated lesson plans.

Prompt starter:

```text
Create a Vietnamese Grade 9 Geography lesson plan following GDPT 2018 and Cong van 5512. Include digital competence, consolidation questions, answer key, and export to DOCX.
```

Expected structure:

- objectives;
- teaching materials;
- learning process;
- activities with objective, content, product, implementation;
- consolidation and review;
- appendix and answer key.
